Changelog V2.5.0.0:
Release Date: 15 Okt 2026

What's New?
 - Reworked and massively expanded font randomisation settings

Changes:
 - Make the connector beams have a lighter colour when the setting it branched away from is disabled
 - Made a new config file for advanced controls, aptly named "adv_config.ini". Some old settings were moved to it
 - Made the parent checkboxes (like the icon randomisation one) have a square instead of a check mark when not all child settings are enabled
 - Added a "Notes" section to the Changelog file and window

Bugfixes:
